# 测试数据

这里有几份现成 Excel，可以直接拿去试 4 种分析模式 + Agent 对账。

## 文件清单

| 文件 | 场景 | 规模 |
| --- | --- | --- |
| `客户反馈_测试数据.xlsx` | 客户反馈分析（情感/分类/汇总） | 400 × 15 |
| `输出模板_情感分类.xlsx` | 配套"逐行结构化"输出模板 | 6 个输出字段 |
| `渠道商应付明细_测试数据.xlsx` | **供应商对账分析**（内部 vs 实际） | 555 × 9（6 渠道 × 3 月） |
| `渠道商对账单_粘贴版.txt` | 配套的真实对账金额（直接复制到 Agent） | — |

## 数据集结构（客户反馈_测试数据.xlsx）

- **反馈ID** / **客户ID** / **客户姓名** — 标识
- **提交时间** — 2026-01-01 ~ 2026-05-01，覆盖 4 个月
- **客户类型**（VIP / 普通会员 / 新客户 / 流失召回）
- **产品类别**（家居家纺 / 厨房用具 / 智能家电 / 美妆个护 / 母婴用品 / 运动户外）
- **购买产品** — 具体产品名
- **渠道**（线上商城 / 线下门店 / 客服电话 / 微信小程序 / 天猫旗舰店）
- **满意度评分** 1–5
- **处理时长_分钟** — 数值，可做相关性分析
- **是否解决** / **是否VIP** — 布尔
- **业务额_元** — 金额，可做对账 / 分组聚合
- **标签** — 多值字符串数组（『、』分隔）
- **反馈内容** — 中文文本（正向 / 中性 / 负向 各种语气）

## 4 种模式怎么用这份数据

### ① 整表汇总（最快上手）

1. 配置好 LLM 配置
2. 进『运行分析』页 → 模型选『（无模型 · 直接整表汇总分析）』
3. 上传 `客户反馈_测试数据.xlsx`
4. 模式选『整表汇总』
5. 分析目标里写：
   ```
   分析这批客户反馈的整体情况，重点找出：
   1. 各渠道满意度对比
   2. VIP 与新客户的处理时长差异
   3. 哪些产品类别投诉率最高
   4. 是否存在异常时段（例如夜间反馈处理特别慢）
   ```
6. 点开始分析 → 1 分钟左右出 Markdown 报告 + 自动图表

### ② 逐行结构化分析

1. 进『分析模型』页 → 点『+ 新建模型』
2. 点『📂 上传输出模板 Excel』，选 `输出模板_情感分类.xlsx`
3. 自动识别 6 个字段（情感倾向 / 风险等级 / 改进建议 等）→ 保存
4. 进『运行分析』页 → 模型选『情感分类』 → 上传数据
5. 模式选『逐行分析』 → 开始
6. 每条反馈被打标，结果写入新 Excel；图表页能看到情感分布、风险高低、提取标签词云等

### ③ 二者都做

同②，但模式选『二者都做』——先逐行打标，再用打标后的数据生成整体报告。

### ④ 🤖 Agent 智能分析

1. 进『运行分析』页 → 模式选『🤖 Agent 智能分析』
2. 上传 `客户反馈_测试数据.xlsx`
3. 在『分析目标』里**每行写一个任务**：
   ```
   找出满意度最低的 3 个产品类别，做柱状图
   计算满意度评分和处理时长的相关系数
   把负向反馈按渠道分组聚合，看哪个渠道最差
   找出处理时长 > 200 分钟的异常订单
   ```
4. 点开始 → 自动跳到『Agent 中心』看实时进度
5. 完成后弹 toast，点击查看图表与洞察

### 对账分析（Agent 模式）

数据集里 `业务额_元` 字段可以做对账。在 Agent 任务里写：
```
渠道商对账：线上商城应到 50000，线下门店 38000，
微信小程序 20000，天猫 45000，客服电话 15000。
做差额对比表 + 柱状图。
```
Agent 会调用 `reconcile` 工具自动算每个渠道的差额 + 自动出对账图。

## 🎯 专项场景：供应商对账分析

这是真实的运营场景——**你的系统里有应付每个渠道商的金额，但他们月底给你的对账单总是有差异**。
我专门做了一份数据 + 真实对账单方便你试。

### 数据集结构（`渠道商应付明细_测试数据.xlsx`）

- **555 行** 内部应付明细，覆盖 **6 个渠道商**（美团 / 饿了么 / 抖音外卖 / 京东到家 / 顺丰同城 / 闪送）
- **3 个月**（2026-02 ~ 2026-04）
- 每行：流水ID / 日期 / 月份 / 渠道商 / 服务类型 / 订单数 / 应付金额 / 状态 / 备注
- **故意埋了不同模式的差异**，等 Agent 来发现：
  - 美团：实际比内部 **+3%**（服务费没算）
  - 饿了么：实际比内部 **-4%**（内部多算了一笔）
  - 抖音外卖：基本一致（差额 < 0.5%）
  - 京东到家：**3 月漏一笔大单 -10%**
  - 顺丰同城：完全一致 ✅
  - 闪送：实际比内部 **+5%**（运费上调没同步）

### 怎么用（Agent 模式）

1. 上传 `渠道商应付明细_测试数据.xlsx`
2. **打开 `渠道商对账单_粘贴版.txt`**——里面已经写好 4 个任务，复制粘贴到分析目标即可
3. 点开始分析

效果：Agent 会调 `reconcile` 工具，每个月跑一次：
- 自动按 `渠道商` 聚合 `应付金额_元`
- 和你给的真实账单逐项对比
- 输出每渠道差额表（+/− 金额、百分比）
- 自动生成内部 vs 实际对比柱状图
- 第 4 个任务汇总 3 个月，按差额绝对值排序找出问题最大的渠道

### 单月简化版（懒人套餐）

只想试一下：
1. 上传 `渠道商应付明细_测试数据.xlsx`
2. Agent 模式分析目标贴：
   ```
   把数据先按 月份=2026-04 筛选，再以渠道商分组对账分析。
   实际账单：美团 21351、饿了么 10394、抖音外卖 11047、
   京东到家 8923、顺丰同城 5611、闪送 3924。
   ```
3. 一个任务搞定，看到内部 vs 实际的柱状图 + 差额表

## 重新生成

需要不同的随机数据：

```bash
python samples/generate_sample_data.py    # 客户反馈数据（400 行）
python samples/generate_template.py       # 输出模板
```

`generate_sample_data.py` 里把 `random.seed(42)` 改掉，每次产出都不一样。
